# 万象漫画首页

依据 Figma 文件 Y23，节点 `1:3455` 实现的原生 HTML/CSS/JavaScript 页面。

## 本地预览

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

打开 http://127.0.0.1:5173 。验收视口为 1920×1080；原稿完整画板为 1920×5495。较窄视口等比缩放画板，以保持原稿布局，未另行设计移动版。

## 实现

- 全部封面、广告、装饰、背景与图标来自原稿并存储于 `assets/`，无临时 Figma URL。
- 六列漫画卡片、两组双行分类、榜单、应用推广区、页脚按原稿尺寸实现。
- 支持换一换、榜单标签选择、广告关闭、返回顶部、漫画预览。
- 搜索、登录、VIP、下载与推广入口未接入后端，点击后显示明确的原型状态。
- 字体优先使用本机 PingFang SC 与 Bodoni 72 Oldstyle，英文标识使用本地 Bruno Ace。非 macOS 环境中文字体回退，可能存在字形差异。
- 原项目文件存于 `previous-version/`。Figma 结构参考存于 `design-context/`。

已通过 Chrome 验证：1920×1080 首屏、1920×5495 全页、390px 宽度无横向溢出，48 张卡片图片正常、无页面脚本错误，换一换与弹窗、榜单标签交互正常。

Lighthouse（1920×1080，本地预览）：性能 75，可访问性 100。为保留原稿像素，使用无损图片；背景等大资源仍影响慢网络下的 LCP。原始 PNG 保留，页面使用无损 WebP 与首屏以下延迟加载。

## 多排行榜

首页排行榜以四列同时展示人气榜、收藏榜、新作榜、飙升榜，每列显示六项内容，并提供独立的“更多”链接。

- 顶部时间筛选支持日、近7天、近15天、近30天，同步更新四列榜单。
- “更多”导航至 `rankings.html?board=popular&period=7` 等实际页面，保留当前榜单与时间范围。
- 详情页支持切换榜单、时间范围、漫画预览，以及返回首页排行榜；页面可直接访问和刷新。
- 详情页支持手机布局；首页继续沿用1920px画板缩放方式。
- 未知榜单或时间参数回退至人气日榜。
- 共享示例数据位于 `ranking-data.js`，目前未接入真实统计接口。

已在 Chrome 验证四列并排、四个独立详情跳转、时间筛选传递、详情页切换及390px无横向溢出，未发现页面脚本错误。

排行榜封面现为68×86px，统一增加万象品牌水印；前三名采用斜切徽章，其余名次使用两位编号。统计值使用独立的数字与单位层级，万级数据简写并保留悬停完整值，增幅单独强调。扩展排行榜高度后，后续板块下移300px，当前页面总高度5795px。详情页同步使用品牌水印与统计值样式。

首页榜单现采用单封面展开：每列默认展开第一名，鼠标移入或键盘聚焦其他条目时切换封面，离开该列后恢复第一名。未展开条目仅显示名次、标题和统计值，不再保留原来的常驻封面。大封面与品牌水印保留；切换时间范围重新展开第一名。收紧榜单高度后，页面总高度为5585px。

排行榜每项显示三个分类标签（台湾、动作、武打），使用原稿橙色漫画气泡资源，收起与展开状态均保留。榜单详情页同步使用同一标签组件。已验证24项均有三个标签且无标签溢出。

排行榜标签改为独立的浅色描边样式，地区标签使用荧黄浅底，题材标签使用淡紫底。每项新增观看量和喜欢量及 Tabler 官方图标；计数位于分类标签下方，悬停可查看完整值，时间范围切换同步更新。首页和详情页共用同一展示组件。计数仍为本地示例数据。
